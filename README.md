# Serina Zou · Portfolio

Source code for my UX and product design portfolio.

**Live site → [serinazou.com](https://serinazou.com)**

I'm a Statistics student at the University of Michigan with a minor in UX Design, graduating in May 2028. I design and build digital products, and I'm looking for UX / product design internships for Summer 2027.


## How it's built

- Plain HTML, CSS and JavaScript, with no framework or build step
- Hosted on GitHub Pages, with a custom domain through Cloudflare
- Case pages share one stylesheet and one script, so every case study uses the same layout
- Videos are exported at full resolution and play only while they're on screen
- 

To view it locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder and go to `localhost:8000`.
